# Data Cleaning & Preparation | DecodeLabs Internship

## 📌 Project Overview

This project was completed as part of my Data Analytics Internship at DecodeLabs.

The objective was to clean and prepare an e-commerce orders dataset using Microsoft Excel, ensuring data quality, consistency, and reliability.

## 📊 Dataset Information

- **Dataset:** E-commerce Orders
- **Total Records:** 1,200
- **Total Columns:** 14
- **Tool Used:** Microsoft Excel

## 🎯 Project Objectives

- Identify and handle missing values.
- Check for duplicate Order IDs.
- Validate date formats and numeric data types.
- Identify invalid numeric values.
- Prepare a cleaned dataset.
- Document data quality checks and cleaning decisions.

## 🧹 Data Cleaning Process

### 1. Missing Values
- Identified 309 missing values in the `CouponCode` column.
- Replaced missing coupon codes with `No Coupon`, based on the assumption that these orders did not use a coupon.
- Verified that no missing values remained.

### 2. Duplicate Detection
- Checked Order IDs for duplicates.
- Found 0 duplicate Order IDs.

### 3. Data Type Validation
- Checked date values and their Excel data types.
- Validated numeric columns, including Quantity, UnitPrice, ItemsInCart, and TotalPrice.
- Checked for zero, negative, and decimal values where inappropriate.

### 4. Data Quality Report
Created a separate report documenting:
- Missing-value checks
- Duplicate checks
- Data-type validation
- Invalid-value checks
- Cleaning decisions
